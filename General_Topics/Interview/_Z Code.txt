Part 1: Bit Manipulation (The Foundation)
How do you set a specific bit (e.g., bit 3) in a variable?

C

int a = 0;
a |= (1 << 3); // Sets bit 3
How do you clear a specific bit (e.g., change 0x03 to 0x01)? (Your Example)

C

uint8_t val = 0x03; // Binary 0000 0011
val &= ~(1 << 1);   // Clears bit 1. Result: 0000 0001 (0x01)
How do you toggle a specific bit?

C

a ^= (1 << 3); // Toggles bit 3
How do you check if a specific bit is set?

C

if (a & (1 << 3)) { /* Bit is set */ }
Write a macro to set a bit.

C

#define SET_BIT(REG, BIT) ((REG) |= (1 << (BIT)))
Write a macro to clear a bit.

C

#define CLEAR_BIT(REG, BIT) ((REG) &= ~(1 << (BIT)))
How do you clear the lower 4 bits of a byte?

C

How do you swap two variables without a temporary variable?

C

a ^= b; b ^= a; a ^= b;
How do you check if a number is a power of 2?

C

// If (x & (x-1)) is 0, it is a power of 2 (assuming x > 0)
if (x && !(x & (x - 1))) { /* It is power of 2 */ }
How do you swap nibbles in a byte (e.g., 0x3F to 0xF3)?

C

unsigned char a = 0x3F;
a = ((a & 0x0F) << 4) | ((a & 0xF0) >> 4);
How do you count set bits in a 32-bit integer?

C

int count = 0;
while (n > 0) {
    n &= (n - 1);
    count++;
}
How do you extract the upper byte of a 16-bit integer?

C

uint8_t upper = (val >> 8) & 0xFF;
How do you combine two 8-bit variables into one 16-bit variable?

C

How do you reverse the bits in a byte (0x80 becomes 0x01)?

C

// Basic loop method
uint8_t b = 0x80;
uint8_t r = 0;
for (int i = 0; i < 8; i++) {
    if ((b & (1 << i)))
        r |= (1 << (7 - i));
}
Write code to test if the 7th bit is set in 0xff000000.

C

Part 3: Function Pointers & Callbacks
Define a function pointer.

C

Write a callback function example (Calculator). (Your Example)

C

#include <stdio.h>

// Define the function pointer type
typedef int (*operation_t)(int, int);

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

// Function accepting a callback
int calculate(int a, int b, operation_t op) {
    return op(a, b); // Executing callback
}

int main() {
    int result = calculate(10, 5, add); // Pass 'add' as callback
    // result is 15
    return 0;
}

Part 4: The volatile keyword
What does volatile mean?

It tells the compiler not to optimize the variable because its value can change unexpectedly (by hardware, ISR, or another thread).
Why is volatile used for memory-mapped peripherals?

Without it, the compiler might assume the value never changes and read it only once, ignoring hardware status updates.
Can a pointer be volatile?

C

int * volatile ptr; // The pointer itself is volatile
volatile int * ptr; // The value pointed to is volatile (typical for registers)
Can a variable be both const and volatile?

Yes. Example: A read-only hardware status register. The program shouldn't change it (const), but hardware changes it (volatile).
Write a delay loop that won't be optimized away.

C

void delay(int count) {
    volatile int i;
    for (i = 0; i < count; i++);
}
Part 5: static and Storage Classes
What is static inside a function?

The variable retains its value between function calls.
What is static outside a function (global)?

Limits the scope of the variable/function to that specific file (private to the file).
What is extern?

Declares a variable/function that is defined in another file.
What is the register keyword?

Hints to the compiler to store the variable in a CPU register for faster access.
Where are local variables stored?

Stack.
Where are global initialized variables stored?

.data section.
Where are global uninitialized variables stored?

.bss section (initialized to zero by startup code).
Part 6: Structures and Unions
What is the difference between Struct and Union?

Struct: Size is sum of members (plus padding). All members exist simultaneously.
Union: Size is size of largest member. Members share memory.
Why use Unions in embedded?

To access the same memory in different ways (e.g., as bytes or as a 32-bit word).
Code Example: Union for Register Access.

C

union Data {
    uint32_t word;
    struct {
        uint8_t b0;
        uint8_t b1;
        uint8_t b2;
        uint8_t b3;
    } bytes;
};
What is Structure Padding/Packing?

Compilers add gaps (padding) to align data with processor architecture.
Packing removes gaps to save space (using #pragma pack or __attribute__((packed))).

Part 8: Interrupts (ISRs)
Can an ISR return a value?

No.
Can you pass parameters to an ISR?

No.
What should be avoided inside an ISR?

printf (slow/blocking), malloc (non-deterministic), floating point operations (context save overhead).
How do ISRs communicate with the main loop?

Using volatile global flags or ring buffers.
What is interrupt latency?

Time from the hardware signal to the execution of the first instruction of the ISR.
What is a nested interrupt?

A higher priority interrupt interrupting a lower priority ISR.

Reverse a string in place.

C

void reverse(char *s) {
    int i = 0, j = strlen(s) - 1;
    while (i < j) {
        char temp = s[i]; s[i] = s[j]; s[j] = temp;
        i++; j--;
    }
}
Convert String to Integer (atoi implementation).

C

int my_atoi(char *str) {
    int res = 0;
    while (*str >= '0' && *str <= '9') {
        res = res * 10 + (*str - '0');
        str++;
    }
    return res;
}
