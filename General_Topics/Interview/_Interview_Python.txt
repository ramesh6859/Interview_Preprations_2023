06.	What is Python’s garbage collection, and how does it work?
	Python uses automatic garbage collection to free memory by removing objects that are no longer in use. It uses reference counting to track how many references exist for an object, and when the reference count drops to zero, the object is destroyed. Additionally, Python uses a cyclic garbage collector to detect and handle circular references that reference counting alone can’t resolve.

09.	What is the Global Interpreter Lock (GIL) in Python, and why is it important?
	The GIL is a mutex in Python that protects access to Python objects, preventing multiple native threads from executing Python bytecodes simultaneously. This lock ensures that only one thread runs in the interpreter at a time, which simplifies memory management but can be a performance bottleneck for CPU-bound tasks in multi-threaded programs.
	
10.	Explain what memory management techniques Python uses.
	Python uses dynamic memory allocation, managed by the Python memory manager, which allocates heap space for objects. Python also uses reference counting and a cyclic garbage collector to manage memory and clean up unused objects. Additionally, Python optimizes memory for smaller objects using pools and arenas.
	
11.	Explain string interning in Python and its impact on memory usage.
	String interning is an optimization technique in Python where identical immutable strings are stored only once in memory. This reduces memory usage and improves performance when comparing strings. Python automatically interns certain strings, like small strings or identifiers.

21.	How do you merge two DataFrames in Pandas?
	You can merge two DataFrames using the merge() function in Pandas, similar to SQL joins. You can specify the type of join (e.g., inner, outer, left, right) and the key(s) on which the DataFrames will be merged. 
	Example:
		import pandas as pd
		df1 = pd.DataFrame({‘ID’: [1, 2, 3], ‘Name’: [‘Alice’, ‘Bob’, ‘Charlie’]})
		df2 = pd.DataFrame({‘ID’: [1, 2, 4], ‘Score’: [85, 92, 88]})
		result = pd.merge(df1, df2, on=’ID’, how=’inner’)
		print(result)  # Output: merged DataFrame with common ‘ID’
		
22.	What are the differences between loc[] and iloc[] in Pandas?
	loc[] is label-based, meaning it selects rows and columns by labels or boolean conditions. iloc[], on the other hand, is integer-based and selects rows and columns by index positions. 
	Example:
		df = pd.DataFrame({‘A’: [10, 20, 30], ‘B’: [40, 50, 60]})
		print(df.loc[0, ‘A’])  # Output: 10 (by label)
		print(df.iloc[0, 0])   # Output: 10 (by index position)

24.	What is binary search, and how does it work?
	Binary search is an efficient algorithm for finding an item in a sorted list. It repeatedly divides the search space in half, comparing the target value to the middle element, and continues until the item is found or the search space is empty. Its time complexity is O(log n).

26.	How can a function be written to determine whether a given string is a palindrome?
	Define a function that compares the string to its reverse. If they are the same, the string is a palindrome. This can be done using slicing in Python.
	Example:
		def is_palindrome(s):
			# Remove spaces and convert to lowercase
			cleaned_s = ”.join(s.split()).lower()
			return cleaned_s == cleaned_s[::-1]
			
		# Example usage
		print(is_palindrome(“A man a plan a canal Panama”))  # Output: True
		print(is_palindrome(“Hello”))  # Output: False

28.	How would you find the maximum value in a list without using built-in functions?

		def find_max(lst):

30.	Write a function to calculate the factorial of a number.
	def factorial(n):
		if n == 0 or n == 1:
			return 1
		return n * factorial(n – 1)
